## How it works

`entry.png` is the finished 1024×1024 front page (composed as HTML/CSS and
screenshotted with headless Chromium, so every headline is crisp and legible).
`main.ts` (Node 22, stdlib only, no network) copies it to
`/output/entry.png`. Running it twice writes byte-identical output.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
